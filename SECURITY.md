# Security policy

Tavern Games handles staked games and a shared gold ledger between guild members, so a way to cheat
(see hidden cards, choose the deck or the dice, forge a result) or to change someone else's debts is a
security problem.

## Reporting

Please **do not open a public issue** for these. Report them privately through
[GitHub's private vulnerability reporting](https://github.com/goofy5752/TavernGames/security/advisories/new)
(Security tab → "Report a vulnerability"). Include the game, the steps, and what a cheating client
can gain.

You will get an answer within a week. Fixes are released as a new addon version, and the report is
credited in the release notes unless you prefer otherwise.

## Supported versions

Only the latest release is supported. Players at one table should run the same version.
