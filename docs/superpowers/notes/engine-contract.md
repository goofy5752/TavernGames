# Engine contract for the parallel engine tracks (Сантасе, Белот, Табла, Холдем)

Binding for every engine written in parallel. Written 2026-11-21 by the controller. The session/fairness/UI integration of each game comes later (stages B–E); these tracks build **only the pure engine + its tests** (and Belot's parity tooling), so the integration can plug them in unchanged.

## Base contract (stage 1, see `engines/tictactoe.lua`)
- File `engines/<id>.lua`, starts `local _, ns = ...; ns.Engines = ns.Engines or {}`; `local E = { id = "<id>", minSeats = n, maxSeats = m, ... }; ns.Engines.<id> = E`; ends `return E`.
- Pure Lua 5.1: no WoW API, no globals, no `bit`, no `math.random`/`math.randomseed`, no `os.*`. Deterministic from input. Integer arithmetic only where it matters (`%`, `math.floor`).
- `E.new(opts) -> state`; `E.apply(state, seat, action) -> true | nil, reason` mutates `state` in place and must leave `state` untouched when it rejects; `seat == 0` = the table (system actions). `E.legal(state, seat) -> {action,...}` (every legal action for that seat now; `{}` if none). `E.auto(state, seat, random) -> action|nil` (a legal action for the seat on turn, nil off-turn; `random(lo,hi)` may be used, never `math.random`). `E.system(state) -> action, delaySeconds | nil` (what the table does next: deal, next hand, ...; the host applies it at seat 0). `E.snapshot(state) -> table` / `E.restore(table) -> state` (plain-data deep copies; snapshot must contain only strings/numbers/booleans/tables, no functions, no cycles).
- Actions are small plain tables `{k = "<verb>", ...}` with short keys (they go over the wire).
- Stage A optional fields you must provide: `E.options` (array of `{id, choices = {...}, default}`; chosen values reach `E.new` as `opts.opt`), `E.new(opts)` also gets `opts.first` (starting seat) and `opts.seats` (array of booleans, occupied at start), `E.result(state) -> nil | {winners = {seat,...}, losers = {seat,...}}` once the **match** has ended, `E.over(state)`, `E.leave(state, seat)` (a seated player left while live: must not fail; for 2-player games and Belot this ends the match with the leaver's side as losers; Hold'em folds them and removes them after the hand), `E.start` (`"host"` for Hold'em only; others start when every seat is filled).
- Rejection reasons are short strings: `"seat"`, `"turn"`, `"phase"`, `"action"`, `"card"`, `"move"`, `"amount"`, ...

## Cards (Сантасе, Белот, Холдем)
- Card face = 2-char string: rank `2 3 4 5 6 7 8 9 T J Q K A` + suit `C D H S` (♣ ♦ ♥ ♠). E.g. `"TS"` = 10♠, `"9H"`.
- **Cards are tracked by deck index.** A hand starts with the system action `{k = "deal", deck = {face1, ..., faceN}}` — the full shuffled deck order (it will come from the commit-reveal shuffle; tests pass fixed decks). The engine stores `state.deck[i]` (face) and keeps every hand, pile, stock, trick, board as **arrays of deck indices**. Dealing order is fixed by the engine (document it at the top of the file; for Belot it must match BelotGameEngine's dealing so parity fixtures line up).
- `E.view(state, seat) -> state'`: deep copy in which every `deck[i]` the seat may not see is `nil` (indices and array lengths unchanged). `seat` 0/nil = a watcher. Visible = own hand, cards on the table, taken tricks if the rules let players look (Сантасе: no, only the last trick; Белот: only the last trick), face-up trump, community cards, showdown cards, everything at match end. The undealt part of the deal action is never visible.
- `E.apply` must work **both on the full state and on any `E.view(...)` of it**:
  - A play action carries both index and face: `{k = "play", i = <deck index>, c = <face>}`. On a view where `deck[i]` is nil it sets `deck[i] = c`; where known it rejects a mismatch (`"card"`).
  - A rule that needs hidden information (e.g. "must follow suit" for an opponent whose hand is unknown) is checked only when every needed face is known; otherwise skipped. The full replay after the seeds are revealed (stage B) re-runs every action on the full state and flags the hand if anything was illegal — so the full-state check must be complete and strict.
  - `{k = "show", cards = {[i] = face, ...}}` at seat 0 fills faces on a view (used for: my own dealt cards, my drawn card, face-up trump, flop/turn/river, showdown, last trick). On the full state it is a no-op if the faces match, else rejected.
  - `E.legal`/`E.auto` for a seat must use only what `E.view(state, seat)` shows (bots and timeouts run on views).
- Provide `E.hidden(state, seat) -> {i, ...}`: deck indices the seat holds that the others cannot see (used later to verify "every played card was in the player's hand").

## Dice (Табла)
- Dice come as a system action `{k = "dice", d = {a, b}}` (1..6 each; produced later by commit-reveal; tests pass fixed values). No hidden information: `E.view` may be the identity (still provide it).
- A full turn is one action `{k = "move", steps = {{from, to}, ...}}`; partial staging („Върни“/„Готово“) is a UI concern. `E.legal` returns every distinct legal full move (dedupe by resulting position), respecting: use both dice when possible; if only one can be used and either could, the larger; doubles = 4 moves; no legal move → the only legal action is `{k = "move", steps = {}}`.

## Tests
- `tests/engines/<id>_test.lua`, the repo's own runner (look at `tests/engines/tictactoe_test.lua` and `tests/run.lua` for `describe/it/eq/ok`; every test must assert something — the runner fails tests with zero assertions). Run `bash t.sh tests/engines/<id>_test.lua`, then the full `bash t.sh` (must stay green).
- Fixed decks in tests, written as face arrays. Include for every card engine: a full hand played on the full state AND replayed on each seat's view with `show` actions giving that seat what it legitimately sees — both must end in the same scores; a view never contains a face the seat should not see; `snapshot/restore` round-trip mid-hand; `auto` always returns an action that `apply` accepts (fuzz: play 200 hands from deterministic pseudo-random decks driven only by `auto` with a seeded LCG you write in the test, assert they all finish and the match ends).
- `TavernGames.toc`: add your engine under `# Engines` after the existing engine lines (the toc test checks every Lua file is listed). Nothing else in the TOC.

## Scope fence

## Addendum
- Every card engine exposes `E.DECK`: the canonical unshuffled face list (Сантасе 24, Белот 32, Холдем 52). The fairness layer will produce a permutation `p` of `1..#E.DECK` and the deal action carries `deck[i] = E.DECK[p[i]]`.
- Each track writes a rule table at the top of its engine file (short, numbered rules, the exact numbers) — this is what reviewers check the code and tests against, and what the rules book will later be written from.

## Addendum 2 (stage B, fairness integration)
- **Randomness marker `need`.** `E.system(state)` returns the action `{k = "deal", need = "deck"}` (card engines) or `{k = "dice", need = "dice", ...}` (Табла) when the table must supply randomness. The session never applies such an action itself: it asks the extensions (`need` hook), and whoever supplies the payload (`deck = {...}`, or `d = {a, b}`) applies the same action **without** `need`. `E.apply` rejects an action still carrying `need` with `"need"`.
- **view + deck.** `E.view(state, seat)` changes nothing but `deck` (faces the seat may not see are `nil`) and sets `full = false`. A copy of any view that has the whole deck and `full = true` must behave exactly as the full state (this is how `Fair.audit` replays a hand once the seeds are revealed). `{k="deal"}` on a view accepts no deck or any subset of the faces; on a state with `full == true` it accepts only a complete permutation of `E.DECK`.
- **`{k = "void"}` at seat 0.** While a hand runs: annul it (nothing scores) and go back to the phase in which `E.system` asks for the deal; in any other phase reject with `"phase"`. Used when the dealer lost the deck (reload) or stood up mid-hand.
- **`E.again`.** `true`: once the match is over (`E.over`), the host may start a new one with `client:startGame()`; the previous loser leads (`E.nextFirst`).
- **`E.auto`/`E.legal` on unknown faces.** They return nothing for a hand whose faces the view does not show (bots and timeouts run on views).
- Extension hooks run under `pcall` in the session (an error is logged and counts as `nil`; re-raised only with `env.strictHooks`, tests): `act`, `applied`, `auto`, `adopted`, `hostChanged`, `need`, `table`, `snap`.
- `SNP.fr` for card games: always present, `{n}` when no round is open, else `{h, d, p, c, st, n}` with `p` the occupied seats strictly ascending.

## Addendum 3 (stage B final fix wave, 2026-11-21)

Nothing here changes an engine's rules or the `E.*` functions; it changes what the fairness extension (`core/Deal.lua`) and the session do around them. Engines written against Addendum 2 need no edit.

- **`{k = "void"}` and the dealer (ruling PB6 changed).** The engine's side is unchanged: the hand is annulled, nothing scores, the engine goes back to the phase in which `E.system` asks for the deal and keeps its own notion of who deals/leads. The fairness dealer (who holds the deck) is no longer the same seat again: the count of deals `n` is not taken back, so the next deal is made by `p[(n + 1) % #p + 1]` with the old `n + 1`, i.e. the next seat. An engine must therefore not assume that the seat that supplied a voided deck supplies the next one.
- **Dealer of a round, restated.** `n` = deals made in this match (not hands completed). Shuffling (`st` = `commit`/`seed`): `d = p[(n + 1) % #p + 1]`. Dealt (`st` = `dealt`/`done`): `d = p[n % #p + 1]` (the same formula with `n - 1`). `SNP.fr` is checked against this on adoption.
- **Public faces only.** The host applies a dealer's `deal`/`show` request on a copy of its state and refuses it when a face in it is not in `E.view(state_after, 0).deck`. So `E.view(state, 0)` must show, right after a deal or a show is applied, every face that deal or show is allowed to publish (the turned-up trump, shown marriage partners, the whole deck once the match is over), and nothing else.
- **`SNP.fr` is validated like `open`.** A round arriving in a snapshot must fit: integers `h`, `d`, `n >= 0`; `p` strictly ascending seats of the table, at least two; `h` not above the snapshot's `q`; the dealer as above; for a round new to the member, from the host it knows: `h` above every round it has seen and events in between, and while shuffling every seat of `p` occupied and the member itself in `p` unless it just sat down. A round that does not fit is dropped (no round; a deal on it closes `"bad", "commit"`). An `open` event must carry `h = seq + 1`.
- **Commits are held.** The first commit a client sees for a seat in a round (event or snapshot) is kept for the round and the audit checks the revealed seeds against those. Another value later is a foul. The commit under a client's own seat must be the commit of its own seed (a client that logged in again mid-round cannot know and accepts what the snapshot shows); the seed revealed for the seat it committed at must be its own seed.
- **Fouls and new reasons of `"bad"`.** A foul noted against a round decides its verdict however the round ends (reveal, noreveal, void, replaced by a new open). Reasons now: `seeds`, `commit`, `deal`, `dealt`, `play`, `noreveal` (as before) plus
  - `mine`: my commit or my seed was replaced;
  - `round`: a snapshot changed my round (participants, dealer), dropped or ended it at the very event I am at, or was pushed on me unasked and skipped events of a hand I held whole;
  - `forged`: an event for my seat that I did not send (engines with `view` only: there the host never moves for another seat and a timeout is played by the seat's own client), or a void in my name while I hold the deck and my seat;
  - `nodeal`: a shuffle that had every commit was opened again although nobody left: the dealer had the seeds and did not deal within `FAIR_WAIT`. Not on a client that knows better (a participant that never sent its seed; a dealer that lacked a seed or whose deal request was lost): those close it `"unseen"`. The same dealer deals the reopened round.
  - `play` also covers an event of the host that the member's engine refused during a hand it had seen whole.
- **`"unseen"` needs a reason.** It is the verdict only when the client came or logged in again mid-hand, the host changed, or the client asked for the snapshot (`SYN`, `WAT`, `SIT`) after losing events. Even then the audit checks the seeds against the held commits and every face the client was shown or sees against the revealed deck (`"bad"`, `commit`/`seeds`/`dealt`/`deal`); only the replay of the moves is skipped. `Fair.audit` returns `"unseen"` itself when `rec.base` is nil; `rec.faces` = the faces of the client's state.
- **Voids and no-deals are named and counted.** `s.fairVoids[name]` per dealer and match; `s.fairLast.n` on such a verdict; `Deal.status` returns `"fair.voidBy", name` or, from the dealer's second one, `"fair.voidMany", name, n`; `Deal.alarm(s)` (the line is red) is true after a bad hand, a complaint, or a dealer's second void/no-deal in the match.
- **Complaints.** `ACT {k="fair", op="protest", h, why}` → `EV` seat 0 `{k="fair", op="protest", h, seat, why}`, `why` one of `mine`, `commit`, `round`, `play`, `forged`, `dealt` (sent only for what the cheated client alone can see: a foul, or private faces that are not the deck's), once per seat and hand, for the running round or the last closed one. Every client keeps `s.fairCry = {h, seat, name, why}` and counts `s.fairCries`; `Deal.status` returns `"fair.protest", name` unless the client's own last verdict is already bad.
- **Hooks.** `adopted(s, prev, m, how)`: `how = {fresh, changed, asked, sat, q}` (a session created by this snapshot; a host or epoch new to me, or I was stale; I asked; I got a seat I did not have; my `seq` before it). New: `refused(s, seat, a)` (member: an event of my host that did not apply), `forged(s, seat, a)` (member, engine with `view`: an event for my seat that I did not send). Both run under `pcall` like the others.
- **New host during a shuffle.** With every commit in, a new host does not open the round again: it waits `FAIR_WAIT` and the dealer asks it for the deal again. With commits still missing it opens again at once, as before.
- **Trace.** `/tavern debug` writes a `PRV` as `cards="<N>"` and a `SED` as `s="<32>"`.
