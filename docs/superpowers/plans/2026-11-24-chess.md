## Review Focus

1. **A move that reaches the host after the mover's time ran out by the host's clock.** Expected: the host refuses it (`"time"`), plays `flag`, and the mover's client shows the lost game, not its own move (Task 4 test `a late move loses to the flag`).
2. **`/reload` in the middle of a staked game, on my own turn.** Expected: the snapshot brings me back, my log of sent moves survives, the running turn is a gift to the seat on turn, and a flag that follows is `unseen`, never `forged` (Task 5 test `a relog keeps my log and makes no false charge`).
3. **The host leaves or goes silent in a timed game.** Expected: the successor arms the flag timer from its own measurement of the running turn; the next game still gives white by seat (Task 4 test `a new host keeps the clock running`).
4. **Garbage in an action or in `dt`** (`f = "e2"`, `f = 0`, `65`, `1.5`, `p = "k"`, a `p` on a non-promotion, `dt = -1`, `0.5`, `"7"`, larger than the time left). Expected: refused with a code, the state untouched (Task 2 test `garbage is refused and changes nothing`).

## Shared decisions (every task relies on these)

- **Squares** are numbers 1–64: `sq = (rank - 1) * 8 + file`, a1 = 1, h1 = 8, e2 = 13, e4 = 29, a8 = 57, h8 = 64. Actions carry numbers only.
- **Pieces** are numbers: white P N B R Q K = 1..6, black = -1..-6, empty = 0. Side to move: `1` white, `-1` black.
- **The engine has the flag `clock = true`** (it runs a chess clock) and `firstSeat = 2`.
- **Time** is whole tenths of a second. `base = minutes * 600`; the increment is `E.INC = 50`.
- **Module names:** `ns.ChessRules`, `ns.ChessSan`, `ns.Engines.chess`, `ns.Clock`, `ns.StakesChess`, `ns.ChessModel`, `ns.ChessPanels`, `ns.ChessHistory`.

**Interfaces — Produces** (`local R = ns.ChessRules`):
- A position `pos` is a table with `board` (64 numbers), `side` (1 | -1), `castle` (a string, the subset of `"KQkq"` in that order, `""` for none), `ep` (the square behind a pawn that just moved two, else `nil`), `half` (plies since a capture or pawn move), `full` (move number, from 1). The engine state of Task 2 holds these fields inline, so every function below takes the state itself.
- `R.start() -> pos`
- `R.fromFen(fen) -> pos` (for tests and the bot's fixtures; no UI reaches it)
- `R.copy(pos) -> pos` (the six fields only)
- `R.attacked(pos, sq, by) -> bool` (`by`: 1 | -1)
- `R.inCheck(pos, side) -> bool`
- `R.moves(pos) -> { {f, t, p}, ... }`: every legal move of `pos.side`; a promotion is four moves with `p` = `"q"`, `"r"`, `"b"`, `"n"` in that order; ordered by `f`, then `t`. Castling is the king's move (e1 → g1: `f = 5, t = 7`), en passant the pawn's move to `pos.ep`.
- `R.find(pos, f, t, p) -> move | nil` (the legal move with exactly these fields; `p` must be `nil` unless the move is a promotion)
- `R.make(pos, move) -> captured` (mutates `pos`; returns the captured piece number, 0 for none; en passant returns the pawn). It updates `castle` (king move, rook move, rook captured on its home square), `ep`, `half`, `full`, `side`.
- `R.key(pos) -> string`: 64 characters of `".PNBRQKpnbrqk"`, then `"w"` or `"b"`, then `castle`, then the file letter of `ep` **only when `R.moves(pos)` holds an en passant capture**.
- `R.status(pos) -> nil | "mate" | "stalemate"` (the side to move has no legal move)
- `R.insufficient(pos) -> bool`: K v K, K+B v K, K+N v K, and kings with any number of bishops all on squares of one colour (either side). Nothing else.
- `R.bare(pos, side) -> bool` (that side has only its king)
- `R.perft(pos, depth) -> number`

State (plain data, snapshot-safe):

```lua
{ board, side, castle, ep, half, full,          -- the position (Task 1), inline
  white = seat,                                  -- the seat that plays white
  turn = seat | nil,                             -- the seat to move; nil once over
  phase = "play" | "over",
  seen = { [R.key] = count },                    -- emptied whenever `half` returns to 0
  moves = { { f, t, p, san, dt }, ... },         -- dt as the event carried it (nil: none)
  taken = { {…}, {…} },                          -- taken[seat]: the piece numbers that seat captured, in order
  base = tenths | nil, clock = { t1, t2 } | nil, -- nil: no limit
  offer = seat | nil,                            -- who offered a draw that still stands
  wait = { 0, 0 },                               -- wait[seat]: own moves before that seat may offer again
  claimed = ply | nil,                           -- #moves when the last claim came
  result = nil | { winner = seat | nil, reason = <code>, left = seat | nil } }
```

Reason codes: `mate stalemate repetition fifty material resign agreed flag flagdraw left`.

- `E.new(opts) -> state`: `opts.first` is the white seat (default `E.firstSeat`); `opts.opt.clock` is the minutes a player (missing: 10; `0`: no limit, `base = nil`, `clock = nil`).
- `E.apply(s, seat, a, dt) -> true | nil, code`. Codes: `action` (not a table, unknown `k`), `seat`, `phase`, `turn`, `move` (not legal, bad square), `promo` (a promotion without `p`, or a bad `p`), `dt`, `time`, `offer`, `clock`, `claim`. Nothing is changed on a refusal.
  - `{k="move", f, t, p}` by the seat on turn. `dt` must be nil or a whole number ≥ 0 (`"dt"`); with a clock, `dt or 0` is taken from the mover's time: a result ≤ 0 is `"time"`, else the time becomes `left - dt + 50`. Then: SAN, `taken`, `seen` (reset when `half == 0`), a standing offer **of the other seat** is dropped and `wait[offerer] = 3`, the mover's own `wait` goes down by 1 (not below 0), the turn passes. Ends, in this order: mate, stalemate, insufficient material, repetition (`seen[key] >= 3`), fifty (`half >= 100`). So a mating move on the hundredth ply is mate.
  - `{k="resign"}` by seat 1 or 2 at any time in play: the other seat wins, `resign`.
  - `{k="offer"}`: only the seat on turn, no offer standing, `wait[seat] == 0`; else `"turn"` / `"offer"`.
  - `{k="accept"}` / `{k="decline"}`: only the seat that did **not** offer, while an offer stands (`"offer"` otherwise). Accept: over, no winner, `agreed`. Decline: the offer is dropped, `wait[offerer] = 3`. Neither touches the clock.
  - `{k="flag"}`: `seat` is the flagged seat; it must be on turn and the game timed (`"clock"` without a limit). Over: the other seat wins (`flag`), or no winner (`flagdraw`) when `R.bare` holds for the other seat's colour.
  - `{k="claim"}`: by the seat **not** on turn, timed game, once per ply (`claimed ~= #moves`, else `"claim"`); sets `claimed = #moves`, nothing else.
- `E.legal(s, seat) -> { {k="move", f, t, p}, ... }` for the seat on turn in play, else `{}`.
- `E.auto(s, seat)`: `{k="flag"}` when the game is in play, timed and `seat` is on turn (the action the table timer plays when that seat's time is gone), else `nil`.
- `E.system(s)` returns nothing. `E.over(s)` is `s.phase == "over"`.
- `E.result(s)`: `nil` in play; a win `{ winners = { w }, losers = { 3 - w }, left = r.left }`; a draw `{ winners = {}, losers = {} }`.
- `E.leave(s, seat)`: in play, the other seat wins, reason `left`, `result.left = seat`.
- `E.nextFirst(prev, occupied) -> 3 - prev.white` (colours follow the seats).
- `E.snapshot`, `E.restore`: deep copies.
- `E.bot(s, seat, random)`: provisional, a uniformly random move of `E.legal` through `random(1, n)` (Task 9 replaces it). Without it a bot's fallback `playAuto` would flag itself.
